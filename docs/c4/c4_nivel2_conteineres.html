[Usuários do Núcleo Familiar & Stakeholders]
Titular, Membro, Auditor e Sysadmin
Acessam a interface responsiva (Mobile-First a Ultrawide — RNF-005) pelo navegador do computador ou smartphone.
▼ HTTPS / Navegador Web + Web Speech API (Voz para Texto) ▼
Fronteira do Sistema FinFamily (Aplicação Monolítica Modular em 3 Camadas)
[Container: Single-Page Application • React 18 + Vite + TailwindCSS]
Interface Web Responsiva (Front-End SPA)
Entrega o Painel de Dashboards interativos, Caixa do Assistente Conversacional com IA (com card de confirmação RN-006), gestão de contas, transações, revisão de CSV, orçamentos e investimentos.
── Chamadas API REST JSON ──►
(Bearer JWT + Criptografia)
[Container: Application Server • Java 21 + Spring Boot 3.3.5]
Servidor de Aplicação e API REST (Back-End)
Concentra todas as regras de negócio (RN-001 a RN-006), autenticação Spring Security + BCrypt + JWT, criptografia AES-256 (RNF-003), cache em memória (@EnableCaching RNF-002), motor de conciliação CSV e agendador @Scheduled.
[Container: Relational Database • H2 Persistente / PostgreSQL]
Banco de Dados Relacional (Spring Data JPA / Hibernate)
Armazena usuários, grupos familiares, membros, contas (com dados sensíveis em AES-256), árvore de categorias, tags, transações, orçamentos, ativos, operações e logs técnicos.
[Container: Disaster Recovery Storage • JSON Snapshots]
Repositório de Backups Diários (RNF-007) & Exportador OpenPDF / POI
Armazena backups automáticos diários com retenção mínima de 30 dias e gera relatórios binários em PDF, Excel (.xlsx) e CSV (RF-010).
▼ Requisição HTTP POST (Timeout < 3s — Seção 11.3) ▼
[External System: LLM Service • HTTP JSON]
Serviço Externo de IA (Google Gemini API / Ollama Local)
Recebe exclusivamente o texto do comando, a data atual e os nomes das contas/categorias para extrair a intenção em JSON.
Notação: Modelo C4 — Nível 2: Contêineres Tecnologias: Java 21 LTS, Spring Boot 3.3.5, React 18, TailwindCSS, H2/PostgreSQL, OpenPDF, Apache POI

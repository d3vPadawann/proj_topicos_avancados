FinFamily • Engenharia de Software (UCSAL)
[Person • Stakeholder]
Administrador Familiar (Titular)
Cria o grupo familiar, gerencia contas, define orçamentos mensais, registra investimentos e convida membros (RF-002, RF-006, RF-007, RF-008).
[Person • Stakeholder]
Membro Familiar (Dependente)
Lança receitas/despesas, importa extratos CSV, utiliza o Assistente IA e acompanha relatórios e contas privadas (RF-003, RF-005, RF-012, RN-001).
[Person • Stakeholder]
Auditor / Consultor Financeiro
Planejador externo com acesso estrito de leitura aos dashboards e relatórios consolidados para consultoria (RF-009, OE4).
[Person • Stakeholder]
Administrador do Sistema (Sysadmin)
Equipe técnica responsável por monitorar logs de segurança e rotinas de backup diário sem ver saldos descriptografados (UC13, RNF-007).
▼ HTTPS / TLS 1.2+ (JSON REST API • Autenticação JWT + Comandos em Texto/Voz) ▼
[Software System]
Sistema FinFamily (Gestão Financeira e Investimentos Familiar)
Centraliza contas correntes, poupanças, cartões de crédito e corretoras; controla orçamentos com alertas em 80% e 100%; concilia extratos CSV sem duplicidade; acompanha carteira de ativos/proventos e integra Assistente Conversacional com IA.
▼ Requisição HTTP JSON (Apenas texto do comando + nomes de contas/categorias — RNF-004)   |   Importação/Exportação de Arquivos ▼
[External System • HTTP API]
Serviço de Inteligência Artificial (LLM API / Motor NLP Híbrido)
Interpreta comandos em linguagem natural em até 3s devolvendo JSON estruturado (intenção registrar ou consultar) sem receber saldos ou CPF (RF-012, RNF-004).
[External Artifact • File System]
Instituições Bancárias (Extratos CSV) & Contabilidade (PDF / XLSX / CSV)
Fornecem arquivos de extrato CSV para conciliação automática (RF-005) e recebem relatórios exportados pelo FinFamily (RF-010).
